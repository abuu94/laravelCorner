## 🛠 Beginner Laravel Projects with Herd

### 1. **Task Manager (To‑Do App)**
- Add, edit, delete tasks
- Mark tasks as complete/incomplete
- Store tasks in a database
- Basics covered:
  - **Routing** (`web.php`)
  - **Controllers & Models**
  - **Database migrations**
  - **Blade templates** for views
  - **CRUD operations**

---

### 2. **Blog Platform**
- Create posts with title & content
- Edit and delete posts
- Show posts on homepage
- Basics covered:
  - **Resource controllers**
  - **Eloquent ORM** for database queries
  - **Form handling & validation**
  - **Pagination**
  - **Blade layouts**

---

### 3. **User Authentication System**
- Register, login, logout
- Protect certain pages for logged-in users only
- Basics covered:
  - **Laravel Breeze/Jetstream** (starter kits)
  - **Authentication middleware**
  - **Session management**
  - **Password hashing**

---

### 4. **Contact Form Application**
- Simple form to send messages
- Store messages in database
- Optionally send email notifications
- Basics covered:
  - **Form requests & validation**
  - **Database storage**
  - **Mail sending (Mailables)**
  - **Environment variables (`.env`)**

---

### 5. **Simple E‑Commerce Store (Mini Shop)**
- List products
- Add to cart
- Checkout (basic order storage)
- Basics covered:
  - **Relationships in Eloquent** (products → orders)
  - **Session storage** (cart)
  - **Blade components**
  - **Database seeding**

---

## 📚 Skills You’ll Practice Across All Projects
- **Routing**: Defining URLs and linking them to controllers.  
- **MVC structure**: Understanding how Models, Views, and Controllers interact.  
- **Database migrations & seeders**: Creating and populating tables.  
- **Blade templating**: Writing dynamic HTML with Laravel’s view engine.  
- **Validation**: Ensuring user input is safe and correct.  
- **Environment configuration**: Using `.env` for database and app settings.  
- **Artisan commands**: Running `php artisan serve`, `php artisan migrate`, etc.
